## Description

This Repo is used to build disk images used to boot virtual machines,each branch has its own purpose as below 


1) master
2) ubuntu -> as name suggests to provision ubuntu images 
3) patch2 -> build alpine images for in uefi mode with nvidia drivers,nvidia container toolkit built in 
4) non-b200 -> build alpine images in non uefi mode with nvidia drivers,nvidia container toolkit built in
